## 1. Propósito y Alcance

Este lente identifica y expone variables numéricas continuas, categorías de segmentación, series temporales y granos analíticos adecuados para la creación de datasets de entrenamiento en Machine Learning y análisis econométrico.

---

## 2. Visibilidad y Responsabilidades Técnicas

- **Variables Numéricas Continuas:** Identificación de variables para regresión y pronósticos de series de tiempo.
- **Grano Estable:** Selección de entidades con granularidad determinista para evitar filtración de datos (data leakage).
