## 1. Propósito y Alcance

Este lente atiende a los ingenieros de sistemas de IA, Machine Learning Engineers y arquitectos de soluciones LLM / RAG. Evalúa la preparación del modelo semántico para integrarse con Feature Stores (ej: Feast, Hopsworks, Databricks Feature Store) y bases de datos vectoriales.

## 2. Visibilidad y Responsabilidades Técnicas

- **Preparación para RAG (Retrieval-Augmented Generation):** Estructuración de descripciones semánticas que puedan ser consultadas por agentes de IA en lenguaje natural.
- **Consultas de Baja Latencia:** Identificación de entidades maestras que requieren caché de inferencia rápida.
- **Normalización de Metadatos:** Compatibilidad de nombres de columnas con herramientas de Text-to-SQL.
