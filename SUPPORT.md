## 3. Reporting Bugs & Issues

If you encounter unexpected behavior, compiler errors, or regression failures:
1. Search [GitHub Issues](https://github.com/AlvaroAlejandroFinOps/SemanticFlow/issues) to verify if the issue has already been reported.
2. If not, open a new issue using our bug report template, including:
   - Python version and OS platform
   - Minimal reproducible Markdown schema or YAML definition
   - Exact CLI command or Python API call executed
   - Full stack trace and expected output
