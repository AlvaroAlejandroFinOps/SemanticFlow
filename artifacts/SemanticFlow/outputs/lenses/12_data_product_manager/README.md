# Data Product Manager Lens - Lifecycle, SLOs & Product Value

**Rol Organizacional:** Data Product Manager (`data_product_manager` / `dpm`)  
**Profundidad Técnica:** `SUMMARY`  
**Áreas de Foco:** `PRODUCT_LIFECYCLE`, `PRODUCT_METRICS`  
**Objetos Visibles:** `FACT`, `KPI`  
**Tema de Color:** `#4C51BF` | **Icono:** `compass`  

---

## 1. Propósito y Alcance

Este lente atiende a los Gerentes de Producto de Datos encargados de diseñar, desplegar y monitorear productos analíticos con enfoque de Data Mesh. Mide la satisfacción del consumidor de datos, el cumplimiento de acuerdos de nivel de servicio (SLAs/SLOs) y el roadmap de funcionalidades.

---

## 2. Visibilidad y Responsabilidades Técnicas

- **Contratos de Datos (Data Contracts):** Especificación clara de entradas y salidas para consumidores internos.
- **Métricas de Adopción y Uso:** Monitoreo de qué tablas y medidas son realmente explotadas por la organización.
- **Gestión de Versiones:** Ciclo de vida semántico y deprecación controlada de métricas obsoletas.
